اربط الواجهة بالمحرك

الواجهة تقرأ الإعدادات والنتائج من الـ repo الخاص وتشغّل الرصد عبر GitHub. يُحفظ المفتاح في متصفحك فقط.

  1. افتح GitHub ← Fine-grained token.
  2. Repository access: Only select repositories ← monitor-engine.
  3. Permissions: Contents = Read and write، Actions = Read and write.
  4. انسخ المفتاح والصقه هنا.

مشروع رصد جديد

اكتب الاسم، واختر مصادر الجمع، والصق ملف الكلمات المفتاحية. المحرك يبني استعلامات الأخبار وإعدادات Apify لكل منصة تلقائياً، وتقدر تعدّل أي صف بعدها.

الصق الملف بالتنسيق أعلاه، أو ملف JSON لمشروع كامل.
