مرصد InfoTimes

كل ما يُكتب عن عملائك، مصنّفاً ومحلّلاً، في مكان واحد.

أخبار بكل اللغات، ومنصات التواصل، وتعليقات الجمهور. يجمعها المحرك، ويستبعد المكرر، ويصنّفها بالنبرة والمحور والموضوع، ثم يكتب التقرير الشهري.

  • مصادر متعددةGoogle News وBing وRSS، وX وفيسبوك وإنستجرام وتيك توك ويوتيوب ولينكدإن
  • تصنيف بالذكاء الاصطناعينبرة وعاطفة ومحور وموضوع، وحقول خاصة بكل عميل
  • تقارير جاهزةتقرير شهري ومقارنة بالشهر السابق والربع، وملف CSV لكل شهر
  • تكلفة تحت السيطرةتقدير قبل كل تشغيل، وسقف إنفاق يوقف الجمع تلقائياً

ربط الحساب

المفتاح يُحفظ في متصفحك فقط، ويقرأ الإعدادات والنتائج من الـ repo الخاص.

كيف أحصل على المفتاح؟
  1. افتح GitHub ← Fine-grained token.
  2. Repository access: Only select repositories ← monitor-engine.
  3. Permissions: Contents = Read and write، Actions = Read and write.

الصق الملف بالتنسيق أعلاه، أو ملف JSON لمشروع كامل.
